# 🚀 FaceAccess

### Sistema de controle de acesso de funcionários com reconhecimento facial e Inteligência Artificial

O FaceAccess é uma aplicação web desenvolvida para modernizar o registro de entradas e saídas de funcionários por meio do reconhecimento facial, oferecendo também informações visuais e relatórios inteligentes sobre as atividades registradas.

## ✨ Principais funcionalidades

- 🧠 **Reconhecimento facial com InsightFace:** identificação de funcionários cadastrados para auxiliar no processo de controle de acesso.

- 📊 **Dashboard interativo:** visualização de indicadores e gráficos sobre entradas, saídas e padrões de acesso.

- 🤖 **Relatórios com Inteligência Artificial:** geração de relatórios diários com base nos registros do sistema.

- 👥 **Gerenciamento de funcionários:** organização dos dados dos funcionários cadastrados.

- 🕒 **Histórico de acessos:** consulta dos registros de entrada e saída.

## 🛠️ Tecnologias utilizadas

- React
- Python
- FastAPI
- Supabase
- InsightFace

## 🎯 Objetivo do projeto

Desenvolver uma solução prática que combine desenvolvimento web, reconhecimento facial, banco de dados e Inteligência Artificial para facilitar o controle de acesso de funcionários.

Este projeto faz parte da minha evolução na área de Engenharia de Software e representa uma oportunidade de aplicar conhecimentos técnicos no desenvolvimento de uma aplicação real.
